01 / INSTALLATION

Your tools. Your workflow.

FreeFlight runs independently. DockPipe uses the same distribution through its planned MCP Registry integration.

Choose a verified build

Check GitHub Releases for published artifacts, checksums and platform evidence. Candidate builds and individual passing jobs do not announce a production release. Code signing and notarization are not currently provided.

A

Standalone

The native bundle supplies the C++ executable, Node runtime, TypeScript Language Service and self-contained Roslyn worker. Default safe-source analysis needs no separate runtime installation.

Tarball and MCPB formats contain the same application. Choose an artifact matching your operating system and architecture, and consult its recorded qualification evidence.

03 / LANGUAGE SUPPORT

Real engines. Honest capabilities.

Capabilities are exposed only when an engine supports them. C#, TypeScript and JavaScript use their established native language services.

All edits are previews; FreeFlight does not write source files. Analyzer diagnostics are not supported. Type hierarchies are currently C#-only. Large-repository scale remains unqualified. Platform results are recorded per candidate and release. Read the exact capability matrix and test evidence ↗

04 / MCP CONFIGURATION

One endpoint. Less setup.

FreeFlight starts with MCP over stdio. The client launches the native server; language workers are internal to the application.

Connect a client

Configure your client with the absolute path to the installed FreeFlight executable and explicitly authorize the workspace you intend to inspect. Use the repository’s exact arguments for your build.

Codex and other MCP clients have different configuration formats. Follow the maintained examples before launching.

View current MCP examples ↗

Keep control of your workspace

Navigation is read-only. Explicitly invoked refactoring tools return structured previews with original-file hashes; FreeFlight does not apply changes to source files.

Default C# analysis does not evaluate MSBuild. Optional trusted-project mode can execute repository code and requires explicit operator startup authorization. Read its trust boundaries before use.

Read security and engine limitations ↗

Use the maintained configuration guide

Complete bundles include their language workers. Workspace access and C# project trust are explicit startup choices. Read the current configuration and trust documentation before connecting your client.
